# Prithwi Singh — Portfolio

Modern, minimal, editorial-style personal portfolio for **Prithwi Singh** — AI Full-Stack Engineer.

Built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features

- **Editorial Aesthetic**: Typography-focused, monochrome design with ample whitespace.
- **Light & Dark Mode**: Persistent theme state with smooth transitions.
- **Separated Data Layer**: All content managed in `src/data/portfolio.ts` for trivial customization.
- **Floating Bottom Navigation**: Compact capsule bar for quick access to social links and theme toggle.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile layouts.
- **Fast & Lightweight**: Zero heavy animation libraries; native CSS transitions and Next.js font optimization.

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + Custom SVG Brand Icons
- **Font**: Inter (Google Fonts via `next/font`)
